# 卧笔隐私政策（模板）

> 这是一个可修改的模板，不是法律意见。上架 App Store 前，请把方括号里的内容替换成真实信息，并放到一个公开可访问的 URL（例如 GitHub Pages）。
>
> 最后更新：[2026-10-20]

**卧笔（Wobi）** 是一个本地 AI 对话客户端。我们尽量少碰你的数据：没有账号体系，没有开发者服务器，没有广告和统计 SDK。

## 1. 我们收集什么

**我们不收集、不上传你的个人数据给开发者。**

具体来说：

- 你在设置里填写的 **Base URL、API Key、模型名、系统提示词**，只保存在你设备本地的 `UserDefaults` 中。
- 你的 **聊天记录** 只保存在设备本地的 `Application Support/wobi-chat.json`。
- 你选择的 **图片** 只在发送时从相册读取并压缩，不会扫描你的整个相册，也不会存到开发者服务器。

## 2. 数据会去哪里

卧笔没有自己的 AI 服务器。当你发送消息或图片时，内容会通过 HTTPS **直接发送到你配置的第三方接口**（例如智谱、阿里云百炼、OpenAI、Kimi、硅基流动、OpenRouter 等）。

这些第三方服务如何收集、使用、存储你的数据，取决于它们各自的隐私政策和服务条款。请在使用前阅读并确认。

你的 **API Key** 也只会发送给该第三方接口，用于身份验证；卧笔开发者无法获取。

## 3. 我们如何使用数据

卧笔不使用你的数据进行广告、画像、分析或训练。App 没有集成第三方统计、广告或推送 SDK。

## 4. 数据保留与删除

- 聊天记录会一直保存在本机，直到你在 App 内开启新对话、删除 App，或手动清除。
- API Key 会保存在本机，直到你修改或删除 App。
- 删除 App 会一并删除本机保存的设置和聊天记录。
- 已发送给第三方接口的数据，需按照该服务商的隐私政策处理，卧笔无法删除。

## 5. 相册权限

卧笔使用系统提供的图片选择器（PHPicker）。只有你主动选择图片时，App 才会读取该图片；App 不会请求完整相册访问权限。

## 6. 儿童隐私

卧笔不面向 13 岁以下儿童，也不会有意收集儿童数据。

## 7. 安全

- 与第三方接口的通信使用 HTTPS。
- API Key 存储在本机 `UserDefaults` 中，未做额外加密。请勿在共用设备上保存敏感 Key；建议使用低额度、可撤销的 Key。
- 由于没有开发者服务器，不存在“开发者数据库泄露”的风险，但你的设备安全仍然重要。

## 8. 第三方服务

卧笔不控制第三方 AI 服务商的数据处理行为。你选择的接口地址、Key 和模型均由你自行提供，相关风险和责任由你与服务商之间的条款约束。

## 9. 政策更新

如果本政策发生重大变化，我们会更新本页面并修改“最后更新”日期。继续使用即表示接受更新后的政策。
