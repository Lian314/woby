# 卧笔 · 常见问题

## 先看：三种场景的费用

| 场景 | 要付 99 美元/年吗？ |
|---|---|
| 自己 iPhone 真机试用 | **不要**。免费 Apple ID + Xcode 即可，描述文件 7 天过期，重新 Run 一次续上 |
| 用 TestFlight 发给别人测试 | **要**。Apple Developer Program，99 美元/年；测试员免费 |
| 上架 App Store 让所有人下载 | **同一笔 99 美元/年**；免费 App 无额外上架费 |

## 费用与 TestFlight

### 1. TestFlight 是免费的吗？

- **测试员**：完全免费。下载 TestFlight、安装卧笔、使用 App，都不用付钱。
- **开发者**：需要 **Apple Developer Program，99 美元/年**（中国区约 ¥688/年，以苹果结算页为准）。TestFlight 不再单独收费。
- **模型调用**：卧笔没有内置 Key。每个用户填自己的 API Key，费用由用户和服务商结算。

### 2. 用户可以“随便下载”吗？

不是“随便搜到就能下”：

- 通过 **TestFlight 公开链接**，任何拿到链接的人都能免费加入；
- 外部测试最多 **10,000 人**；
- 每个构建只有 **90 天**有效期；
- 外部测试的第一个构建要通过 **Beta 审核**；
- App Store 里搜不到它。

想要真正“所有人随时下载”，需要上架 App Store（见 [02-AppStore上架.md](02-AppStore上架.md)）。

### 3. 测试员需要什么？

- 一台 iOS 17+ 的 iPhone；
- 一个 Apple ID（下载 TestFlight 用，免费）；
- 拿到你的 TestFlight 公开链接或邀请邮件；
- 自己的 API Key（否则只能看到设置页，不能聊天）。

### 4. 为什么每个构建只有 90 天？

这是苹果的 TestFlight 规则。90 天后测试员打开会提示过期。重新上传一个构建、把 Build 号加 1 即可。

### 5. 不续费 Apple Developer Program 会怎样？

- App Store 上的 App 可能被下架；
- TestFlight 构建不可用；
- 签名证书失效，需要重新配置。

## 使用与配置

### 6. 卧笔支持哪些服务商？

任何兼容 **OpenAI Chat Completions** 的接口都可以，只要服务商支持 `POST {Base URL}/chat/completions` 和 `Authorization: Bearer <Key>`。内置预设包括智谱、阿里云百炼、OpenAI、Kimi、硅基流动、OpenRouter、DeepSeek。

### 7. 为什么 DeepSeek 不能发图片？

DeepSeek 当前模型是纯文本的，不支持图片输入。要“看图”，选带视觉能力的模型，例如 `glm-4v-flash`、`qwen-vl-plus`、`gpt-4o-mini`、`moonshot-v1-8k-vision-preview`。

### 8. 为什么 Base URL 必须是 https？

iOS 的 App Transport Security 默认禁止明文 HTTP。卧笔有意只允许 HTTPS，避免 Key 和聊天内容在公网明文传输。要连自己的 `http://` 网关，需要改 `Info.plist` 加 ATS 例外（不建议上架版本这么做）。

### 9. 填了 Key 还是提示配置不对？

检查：

1. Base URL 是否是 `https://` 开头、有没有多余空格或结尾斜杠；
2. Key 有没有复制完整、是否已过期/欠费；
3. 模型名是否和服务商文档一致（区分大小写）；
4. 该接口是否是 OpenAI 兼容格式，而不是厂商私有协议；
5. 网络是否能访问该服务商。

### 10. 图片发送失败怎么办？

按顺序试：

1. 确认模型支持视觉输入；
2. 设置里关掉「图片以 Data URL 发送」，再试一次（不同服务商对 base64 格式要求不同）；
3. 换一个预设（智谱、阿里云百炼、OpenAI 的兼容性较好）；
4. 把图片裁小一点（App 已压到最长边 1400px）。

### 11. 回答一直不出现 / 只有“正在思考”？

- 服务商可能不支持流式：到设置里关掉「流式输出」再试；
- 网络超时：本 App 请求超时是 180 秒；
- Key 没权限或余额不足：错误信息会显示在对话气泡里。

### 12. Key 安全吗？

- Key 只存在本机 `UserDefaults`，**没有加密**；
- App 没有开发者服务器，Key 不会发给开发者；
- 请求会直接发给你填的服务商；
- 不要把装了 Key 的手机借给别人；截图时遮住 Key；
- 建议用低额度、可随时撤销的 Key。

### 13. 聊天记录存在哪？怎么删除？

存在本机 `Application Support/wobi-chat.json`。点左上角「新对话」会清空当前对话和本地记录；删除 App 也会删除。没有云端备份。

### 14. 支持 iPad / iOS 16 吗？

- iPhone only，iPad 以兼容模式运行；
- 最低 iOS 17；
- 没有专门做 iPad 分栏布局。

### 15. 为什么没有多会话、语音、代码高亮？

这是刻意的取舍：先把「配置接口 → 聊天 → 看图」做稳做简单。需要的话可以后续加。

## 开发与发布

### 16. 没有 Mac 能开发/发布吗？

不能本地编译。Xcode 只有 macOS 版，苹果也没有 Windows 上传工具。可选：

- 借一台 Mac（最省事）；
- 租云 Mac（MacinCloud、MacStadium、AWS EC2 Mac）；
- 用 GitHub Actions / Codemagic / Xcode Cloud 做 CI（配置签名更复杂）。

### 17. 怎么改 Bundle ID？

Xcode → 选中 Wobi target → **Signing & Capabilities** → 改 **Bundle Identifier**。同时要在开发者后台注册新的 App ID，并在 App Store Connect 里创建/选择对应 App。

### 18. 怎么改 App 显示名称？

改 `Wobi/Info.plist` 里的 `CFBundleDisplayName`。App Store 上显示的名字则要在 App Store Connect 里改（受全局唯一限制）。

### 19. 怎么改图标？

替换 `Wobi/Assets.xcassets/AppIcon.appiconset/AppIcon.png`，必须是 1024×1024、无透明通道的 PNG。也可以改 `tools/make_icon.py` 后重新生成。

### 20. 为什么 `project.pbxproj` 是脚本生成的？

开发环境没有 Mac。`tools/make_project.py` 负责生成工程文件，`tools/validate_project.py` 做静态校验，保证对象引用和文件路径一致。在 Mac 上正常用 Xcode 打开即可；新增文件后重新跑一次生成脚本，或在 Xcode 里直接拖文件。

### 21. 这个项目能直接商用吗？

代码和文档由你自行使用。上架前请自行确认字体/图标/第三方服务条款，以及中国大陆的备案和生成式 AI 合规要求。
