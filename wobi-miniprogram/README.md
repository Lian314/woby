# 卧笔 · 微信小程序预览版

> 这是卧笔的**微信小程序版本**，不是把原生 SwiftUI 工程打包。
> 好处：**不需要 Mac、不需要 99 美元 Apple Developer**，用 Windows 开发，微信扫码就能在 iPhone 上试用。
> 代价：小程序有域名白名单和发布审核限制，自定义接口的域名必须先加到微信后台，也不能上 TestFlight。

---

## 现在能做什么

- 文字对话，支持流式输出（设置里可关）
- 从相册/相机选图，最多 3 张，压缩后发给视觉模型
- 完全自定义：Base URL、模型、API Key、系统提示词
- 图片可切换 Data URL / 纯 Base64
- 设置保存在本机；不经过开发者服务器
- 聊天记录只在本次打开期间保留（小程序本地存储只有约 10MB，暂不持久化图片/对话）

不支持 / 暂未做：

- 任意域名（只能请求微信后台白名单里的 HTTPS 域名，见下）
- OpenAI 等境外接口（域名通常无法加入微信白名单）
- Markdown 渲染、多会话、聊天记录导出
- 上架 App Store / TestFlight（这是另一条路线）

## 五分钟跑起来（Windows）

### 1. 注册一个微信小程序账号（免费）

1. 打开 <https://mp.weixin.qq.com>，点“立即注册” → 选“小程序”。
2. 用一个**没有注册过公众号/小程序**的邮箱注册，按提示做个人主体实名。
3. 注册完成后，在“开发 → 开发管理 → 开发设置”里找到 **AppID**，复制下来。

> 小程序名称全局唯一，“卧笔”如果被占用，可以先用“卧笔 AI 对话”之类的名字；名称以后能改。
> 头像可以直接用 `../wobi-ios/tools/icon-preview.png`（1024×1024）。
> 个人主体注册免费；微信认证是 300 元/年左右，只有部分能力需要，先不用做（以微信后台为准）。

### 2. 安装微信开发者工具

下载 Windows 稳定版：

<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>

安装后用微信扫码登录。

### 3. 导入项目

1. 开发者工具 → “导入项目”。
2. 目录选：`D:\ccode\woby\wobi-miniprogram`
3. AppID 填你刚才复制的；如果想先看模拟器，也可以先用 `touristappid`（测试号）打开。
4. 点“导入”。

> `project.config.json` 里现在写的是 `touristappid`。换成真实 AppID 才能“预览”到手机。
> 直接在开发者工具里改 AppID，或者编辑 `project.config.json` 的 `"appid"` 字段。

### 4. 编译、预览到 iPhone

1. 点顶部“编译”。
2. 点右上角“预览”，会出现二维码。
3. 用 iPhone 微信扫码，打开卧笔。
4. 进入 App 后，点右上角“未配置”，手动填 Base URL、模型和 API Key → 保存。
5. 发一句“你好”，再选一张图试试视觉。

> 预览版不需要发布审核，但**可能需要先配置请求域名和隐私指引**，见下面两节。

## 必须配置：请求域名

微信小程序只能请求**在后台配置过的 HTTPS 域名**，而且域名要 ICP 备案。所以自定义 Base URL 之前，先把它的域名加到微信后台。

配置路径（以微信后台实际界面为准）：

```text
微信公众平台 → 开发 → 开发管理 → 服务器域名 → request 合法域名 → 修改
```

补充：

- 域名必须是 HTTPS，且已 ICP 备案；IP 地址、localhost 不行。
- 换接口就要把新域名加进去；只加你实际会用的域名即可。
- 真机预览/体验版建议直接把域名配好；开发者工具本地调试可以勾选“不校验合法域名”。
- 如果后台不允许直接添加第三方域名（少数情况），就需要自己的代理域名/云函数。
- OpenAI、OpenRouter 这类境外域名通常加不进国内小程序的白名单，需要你自己有已备案的代理。
- 只在开发者工具/真机调试里连自己的 **HTTP** 网关时，可以在设置里打开「允许 HTTP（仅开发调试）」；但预览/体验版/正式版仍然必须 HTTPS + 白名单，HTTP 不能用于发布。

---

## 必须配置：隐私保护指引（选图/相机）

`wx.chooseMedia` 属于微信的隐私接口。正式使用前，需要在后台配置“用户隐私保护指引”，声明用途：

```text
微信公众平台 → 设置 → 服务内容声明 → 用户隐私保护指引
```

按实际情况勾选/填写：

- 选中的照片或视频信息：用于发送给用户配置的 AI 服务做图片理解
- 摄像头：用于拍摄照片提问

配置后，按微信提示授权。如果选图仍然提示隐私错误，先确认指引里勾选了“选中的照片或视频信息”和“摄像头”，再检查当前基础库是否支持隐私授权；必要时按微信文档接入隐私弹窗组件。

## 体验版：发给朋友测试（不用 99 美元）

1. 开发者工具点“上传”，填版本号和备注。
2. 微信公众平台 → 管理 → 版本管理 → 把刚上传的版本设为“体验版”。
3. 在“成员管理 → 体验成员”里添加朋友的微信号。
4. 朋友用微信扫体验版二维码，就能使用。

体验版同样需要：

- 请求域名已配置；
- 隐私指引已配置；
- 朋友被加为体验成员。

> 体验成员数量有限；如果要给不特定的人用，需要正式发布并过微信审核。
> AI 对话类小程序公开发布可能涉及企业主体、服务类目、生成式 AI/深度合成合规，个人主体不一定能过，请以微信审核为准。

## 原理与文件结构

```
wobi-miniprogram/
├─ app.json / app.js / app.wxss
├─ project.config.json      # AppID、urlCheck 等
├─ sitemap.json
├─ pages/
│  ├─ chat/                 # 对话页
│  └─ settings/             # 设置页
└─ utils/
   ├─ endpoint.js           # Base URL → /chat/completions
   ├─ storage.js            # 设置读写
   ├─ api.js                # wx.request + 流式/非流式
   ├─ sse.js                # SSE 解析
   └─ utf8.js               # 分块 UTF-8 解码
```

请求链路：

```text
小程序 → 用户配置的接口 /chat/completions
```

没有开发者后端；API Key 保存在小程序本地存储里，请求直接从小程序发出。

## 已知限制

1. **只能请求白名单域名**：自定义 Base URL 的域名必须先加到微信后台；OpenAI 基本不可用。HTTP 只在开发者工具/真机调试里可用，不能用于体验版或发布。
2. **聊天记录不持久化**：退出小程序后对话清空；设置会保留。
3. **流式输出依赖 `enableChunked`**：不支持时可在设置里关掉，退化为整段返回。
4. **请求超时 60 秒**：特别长的回答可能被截断，重试或关流式。
5. **图片体积**：最多 3 张，自动压缩；过大的图片会提示换一张。
6. **没有 Markdown**：回答按纯文本显示，保留换行。
7. **AI 合规**：自己预览/体验通常不经过审核；公开发布要按微信要求处理类目和资质。

## 常见问题

### 1. 预览时提示“不在以下 request 合法域名列表中”

把域名加到微信后台（见上），或在开发者工具“详情 → 本地设置”里勾选“不校验合法域名”先本地调试。真机/体验版建议直接配域名。

### 2. 选图时提示“需要隐私授权”

去后台配置“用户隐私保护指引”，声明选中的照片/相机用途；配置后重新预览。

### 3. 401 / 404 / 403

- 401：API Key 错、过期、额度不足；
- 404：Base URL 或模型名不对；
- 403：服务商没开通该模型，或域名/IP 被限制。

设置页的 Base URL 必须是 `https://` 开头、不要带 `/chat/completions`（带了也能识别）。

### 4. 图片发出去但模型说看不到

- 确认用的是视觉模型（glm-4v-flash、qwen-vl-plus 等）；
- 设置里关掉“图片以 Data URL 发送”，改用纯 Base64 再试；
- 换一家服务商。

### 5. 回答一直不出现

- 设置里关掉“流式输出”；
- 看对话里红色错误信息；
- 检查域名、Key、模型名；
- 服务商可能不支持流式或请求超时。

### 6. 能不能用 OpenAI？

微信小程序不能直接请求未备案的境外域名。要用 OpenAI，需要你自己有一个已备案的代理域名/云函数，把请求转发出去；这已经超出“无服务器预览版”的范围。

### 7. 这个能上架 App Store / TestFlight 吗？

不能。小程序只在微信里运行。要上 TestFlight，还是得回到 `wobi-ios/` 原生工程，用 Mac + 99 美元开发者账号。

### 8. 为什么聊天记录没了？

预览版刻意没有持久化对话：小程序本地存储只有约 10MB，图片 base64 很容易占满。设置会持久化。

## 隐私与安全

- 不经过开发者服务器，API Key 只存在这台设备的微信小程序存储里；
- 但小程序本地存储是明文，建议使用**低额度、可撤销**的 Key，不要在共用手机上保存；
- 消息和图片会直接发给你选择的第三方模型服务，受该服务商隐私政策约束；
- 正式发布前，请配置微信的“用户隐私保护指引”，并准备用户协议/投诉渠道。
